功能区

    领域 → 子域 → 模块 → 技术点 → 文档 的完整层级。点击节点在图中定位查看；「只看子树」可在上方领域筛选中选择某个领域后点「全貌」。

    加载中…

    自定义导出：选起点节点，向下导到某层级（或到某终点节点）。 JSON 含 vid 与来源链接（可回传再入库），Markdown 为层级大纲。

    展示自上次「确认已审」以来新写入的节点/关联；同一次批量写入（一次请求加多个点/线）合并为一组。 记录永久累积，可用下方时间区间导出；新增节点可「高亮新增」在图中标出。 操作人显示其在登录时填写的标识（也可用 IP 判断）。

    使用「导出知识架构」的 JSON（或同样式的新文件）批量入库： 带 vid 已存在 → 按 vid 指主更新；缺失 → 自动新建；先「校验」看计划，再「确认写入」。

    从技术资料中抽取技术点 / 支撑文档结构，经确认后写入图谱。 单份资料用「手动填写」，多份批量用「批量导入」；抽取 / 导入后都会进入「入库预览」核对，再「确认写入」。

    粘贴一个公开网页 URL（论文/资讯/技术博客），抓取正文后填入「手动填写」文本框，即可继续「自动抽取」入库。

    多份资料批量入库：先点「生成入库格式模板」拿到格式，交给本地 AI 按此把资料处理好（JSON）； 然后粘贴结果，或点「导入 .md 文档」读取文件（.md 里的 JSON 代码块也可以）。 支持一次粘贴 / 导入多份，随后「加载到入库预览」逐份核对，再确认写入。

    从 arXiv / 行业资讯 / 供应商专栏等来源自动抓取 → AI 抽取成「入库格式」→ 进入下方待入库清单，人工确认后写入图谱。来源增删在 backend/collector_sources.json；周期由 COLLECT_INTERVAL_HOURS 控制（默认 24h）。
