AI4KnowledgeNet 知识图谱工作台 · 功能清单

版本：v0.4.0 ｜ 整理日期：2026-08-19
底层：FastAPI + NebulaGraph 3.8.3 + vis-network + 3d-force-graph（WebGL）
访问：浏览器打开 http://<服务器IP>:8000

一、总览

这个工作台把「散落在文件夹里的底盘/汽车技术资料」组织成一棵 领域 → 板块(subdomain) → 主题/技术点(technology) → 材料(material) 的知识网络，并提供可视化、检索、编辑、AI 辅助入库四大能力。所有操作实时写入共享的 NebulaGraph。

二、功能清单（按模块）

A. 可视化与视图

功能说明
2D / 3D 双视图顶部「二维 / 三维」一键切换；3D 用 WebGL 力导向图，2D 用 vis-network
同心圆布局领域/板块按扇形分区，层次清晰（默认）
力导向布局关联越多的节点越被斥力推开，适合看清网络结构
重新撑开力导向下把重叠节点重新推开
缩放 / 拖拽 / 旋转3D 可旋转视角；2D 拖拽画布；「适应」按钮一键居中
3D 节点标注可开关；按层级（领域/子域/技术点/材料）选择显示哪些标签
图例右下角显示各节点类型对应的颜色/大小
节点大小分级领域最大、材料最小，一眼识别层级

B. 检索与定位

功能说明
关键字搜索按技术点/领域/材料名搜索，支持中英文、模糊
类型筛选搜索时可限定只查技术点/领域/子域/材料
高亮命中在图上高亮显示搜索命中的节点（2D/3D 通用），未命中变暗
层级筛选（显示层级）只看某一层：领域 / 子域 / 技术点 / 材料
层级范围「含上层」或「仅本层」
领域筛选只看某个领域（子库），多人协作时隔离不同知识域
节点列表左侧列出当前节点，点击列表中某项即可聚焦

C. 聚焦与探索

功能说明
聚焦子图点任意节点 → 显示它一跳/两跳内的邻居（所属层级 + 支撑材料），自动保留材料球体
只看选中只显示当前选中点及其一跳邻居
节点详情抽屉右侧弹出：节点标签、属性、邻居分组、来源链接
打开链接材料节点可跳转到原文 URL / 复制共享盘路径
查最短路径选起点+终点，FIND SHORTEST PATH 找两点间最短关联网，用于跨技术关联发现

D. 图谱编辑（CRUD）

功能说明
添加技术点填名称、上一层技术簇（可多级）、描述、关键词；支持「提炼/译中」AI 辅助
添加支撑材料填材料名、支撑的技术点、类型（文档/论文/专利/标准/资讯）、标题、摘要、来源链接
编辑节点/边PATCH 改属性；删除节点（连边级联）、删除单条边
数据即时落库任何增删改实时写入 Nebula，刷新即最新态；幂等（IF NOT EXISTS）防重复

E. AI 协助入库

功能说明
LLM 状态检测AI 面板显示是否已配置可用的大模型服务
自动抽取粘贴论文摘要/专利说明 → LLM 抽取「技术点 + 支撑材料」结构（可选译中文）
生成协作提示词把资料整理成提示词，交给 Cursor/助手人工处理
解析粘贴结果把 Cursor 返回的 JSON 粘贴 → 解析 → 预览
确认写入人工确认后的抽取结果一键写入图谱
提炼/译中对描述做 AI 提炼或中译
规则/AI 复核import_review 支持 rule_check + AI 二次复核（QA 环节，先不写库）

F. 系统与运维

功能说明
全貌（Overview）一屏总览整图，按层预算控制画布规模、保证清晰
刷新重新拉取数据
API 访问页面顶部「API」链接，Swagger 文档（/docs）
统计条顶部显示各层节点数量（领域/子域/技术点/材料）
MCP 服务供 AI Agent（如 Cursor）经 kg_* 工具读写图谱，人机协同同一份数据

三、数据模型速查

节点 Tag：domain（领域）、subdomain（板块）、technology（主题/技术点）、material（材料）

边：

  • belongs_to（子→父，层级归属）
  • supports（材料→技术点，材料支撑）
  • relates_to（技术点↔技术点，横向/交叉关联）

四、能力边界（当前已知）

  • 多人协作：共享数据但无登录鉴权、无冲突提示（后写覆盖先写），权限后续补。
  • 实时同步：非自动推送，需刷新页面看他人改动。
  • 材料存储：元数据在 Nebula；文件本体走共享盘/链接，暂未接入对象存储。
  • 批量导入：主要靠脚本（ingest_*.py）+ AI 抽取，页面以增量录入为主。

五、一句话总结

一个「可视化 + 检索 + 编辑 + AI 抽取 + 多人共享」的底盘技术知识图谱工作台，把资料变成可检索、可推理、可持续生长的知识资产。
