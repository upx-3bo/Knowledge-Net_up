# 前端视图升级说明（2026-10-08）

> 用途：知识库打包发给同事后，供其参考对齐同款前端功能。升级对象为三个文件：`frontend/index.html`、`frontend/app.js`、`frontend/styles.css`。
> 升级前请先备份现有文件（复制到任意备份目录）。

## 1. 本期变更清单

### A. 视图 × 布局矩阵（顶部画布视图栏）
- **视图**：`二维 | 三维`（原有）
- **布局**：`树状`（新增） | `同心圆`（原有） | `力导向`（原有）
- 二维/三维都可选布局；三维下「同心圆」自动等同「力导向」（原有力导）。

### B. 二维树状（新）
- 方向：**从左往右**展开；`领域 → 子域 → 技术点 → 文档`
- **种子坐标方案（与同心圆同机制）**：首次进入时按真实层级算好一套初始坐标
  （x=列位×列距；y 按展开方式取子树带中点或顶部），**物理始终关闭** —— 初始呈现为树状，
  之后每个球可**完全自由地上下左右任意拖动**，无任何行列约束，也不会变成力导向
- **初始展开方式可切换**：默认「居中」（子层围绕父节点垂直居中展开），顶栏「居中/顶部」按钮可切为
  「顶部」（父节点顶部对齐"挂载式"）；切换即重新排布初始树
- **固定列位**：按真实层级（child→parent 边）显式计算每层列号（领域=1、子域=2、技术点=3…），
  父列永远在子列左侧；同列节点自动去重保证不重叠
- **「复位」按钮**：顶栏出现（仅二维树状时显示），一键恢复到当前展开方式下的初始树状排布
- 层级边（belongs_to / supports）在树状模式下自动反向为「父→子」用于挂载结构

### C. 三维树状（新，两种布局可切换）
- **分层**（默认）：**按标签固定层高**，领域/子域/技术点/文档各占一层，**同为技术点的一定在同一高度**（初始分层树）
- **环形**：**层级径向树**——**一层一圆（每层级一圈 z 一层）**，子球位于父球角度方向的楔形扇形内（按子树叶子数平分角度），
  连线沿半径短直、基本不交叉；**技术点下面再接的技术点自动落在下一层圆**（层=父层级+1）
- 三维树状时顶栏出现「**分层 / 环形**」切换按钮；x/y/z 按位**钉住**（fx/fy/fz），可旋转/缩放浏览但不抖不窜层
- URL：`#view=3d&layout=tree&tree3d=ring` / `&tree3d=layer`
- 与三维力导（原有）可切换

### D. 分类树侧栏（左侧功能区新增「分类树」面板）
- 完整层级浏览：`领域 → 子域 → 技术点 → 文档`
- 逐级展开 / 折叠；节点计数徽标
- 按钮：「全部展开」「折叠」「刷新」
- 点击任一节点 → 打开右侧详情并高亮

### E. URL 快捷入口
- `http://<服务器IP>:8000/#view=2d&layout=tree`（初始即二维树状）
- `http://<服务器IP>:8000/#view=3d&layout=tree`（初始即三维树状，分层）
- `http://<服务器IP>:8000/#view=3d&layout=tree&tree3d=ring`（三维树状环形布局）
- `layout` 取值 `tree | radial | force`；`view` 取值 `2d | 3d`；三维树状可加 `tree3d=layer|ring`
- 便于直接发给同事查看指定视图

### F. 树状下的协同筛选（复用原有）
- `显示层级` / `领域筛选`（选某领域后点「全貌」= 只看该领域的一棵树）
- **默认只展示「底盘技术」领域**（若库中存在；同事克隆不存在同名领域时自动保留全部），
  看其他/全部领域用「领域筛选」下拉切换
- 只看选中、高亮命中、标注分级均照常生效

### G. 其他小交互
- 布局/视图切换（树状/同心圆/力导向/复位/居中/三维布局）**不再在画布中心弹注释**
- 顶部统计条（领域/子域/技术点/文档数量）**可折叠**：行右侧「▾/▸」按钮收起/展开，收起后自动重新适配画布

## 2. 升级步骤

1. 备份当前 `frontend/` 下三个文件（或整目录）。
2. 用新版覆盖：
   - `frontend/index.html`（视图栏「树状」按钮 + 「分类树」面板）
   - `frontend/app.js`（布局树逻辑、分类树逻辑、URL hash 入口）
   - `frontend/styles.css`（分类树样式）
3. 静/动态文件即时生效，**无需重启服务**；浏览器需 **Ctrl+F5 强刷**（陈旧缓存会导致 JS 失效）。

## 3. 回退

- 用步骤 1 的备份覆盖回三个文件即可，同样免重启、强刷页面。

## 4. 验证自检清单

- 默认打开：节点/边计数正常（如约 265 点 / 255 边）
- 切「树状」：二维从左往右初始树状（默认**居中展开**，可切「顶部」），之后可**自由上下左右拖动**（不会变力导向），顶栏「居中/顶部」「复位」可用；三维为按标签分层的静态树（同为技术点同一高度）
- 点击任意节点：只高亮/打开详情，**不改变布局**
- 「分类树」面板：领域一级可展开到 子域→技术点→文档，点节点能打开详情
- 控制台无报错（F12 → Console）
