# 蓝区检索任务 Prompt（网络隔离 · 供蓝区检索/整理工具参考）

> 任务：围绕「目标主题」全网检索相关汽车技术资讯，按固定格式逐条整理，随文件同步回绿区。
> **蓝区只做"检索 + 事实整理"：不做技术分类、不做评价、不做归纳。** 分类与归纳入库由绿区完成。

## 一、目标主题（每个 run 只检索一个主题；换主题只改这一段）

当前主题：**制动与驱动制动集成（wet brake）**
相关对象：线控制动（EMB / EHB / 液压解耦 Onebox）、湿式制动（wet brake）、鼓式制动、驱动制动集成、驱制一体、轮毂电机与制动集成、驻车制动、制动冗余、能量回收制动等。

> 检索词建议（可扩展，命中任一即收录）：
> `线控制动` `EMB` `EHB` `Onebox` `液压解耦` `湿式制动` `wet brake` `鼓式制动` `驱动制动集成` `驱制一体` `轮毂电机制动` `制动冗余` `驻车制动` `能量回收制动` `brake-by-wire` `regenerative braking`

> 下一次搜集其他方向时：**仅替换「当前主题」与「检索词建议」两行**，其余规则、格式完全不变。

## 二、每条固定字段（缺的写"未说明/未知"，禁止编造）

| 字段 | 要求 |
|---|---|
| 编号 | `CT-YYYYMMDD-序号`，如 CT-20260923-001 |
| 目标主题 | 本 run 的主题（原样复制第一段主题） |
| 技术点/子主题 | **尽力**从原文提取的技术名词，可多个用「、」分隔，如 `EMB` `液压解耦`；提取不出留空 |
| 资讯标题 | 原文标题 |
| 摘要要点 | 原文关键信息 ≥100字，**原样保留细节，不要自己重写/概括** |
| 涉及厂商 / 客户 / 车型 | 原文提到的名字，多个用「、」；无则"未识别" |
| 成熟度 | **只按原文如实标注**：`量产 / 样机发布 / 披露 / 未说明` |
| 原文日期 / 来源（站点·栏目） / 链接 | 出处信息，缺日期写"未知" |
| 命中检索词 | 实际命中的词，用「、」分隔 |
| 备注 | 来源属性如实标注，如 `奖项申报材料` `融资新闻` `发布预告` `研究报告`；一篇内多个事项标 `A/B` |

## 三、必须遵守的规则

1. **相关即收，宁多勿漏**：难以判断是否相关时也收录（备注写"相关性待确认"）。
2. **一篇文章含多个产品/事项 → 各列一条**（同一链接允许多条，备注标 A/B）。
3. **只整理，不加工**：不评价技术优劣、不分类、不推断；不确定的地方按上面字段写"未说明"，严禁编造。
4. **去重**：同标题+同链接只保留一条。
5. **输出 JSON 结构固定**（可含 `briefing.md/csv/html`，但 `.json` 必须存在）：
   ```json
   {
     "meta": {
       "topic": "制动与驱动制动集成（wet brake）",
       "since": "检索起始日期",
       "retrieved_at": "生成时间",
       "sources": "检索来源（站点/栏目）",
       "scanned": 0,
       "hits": 0,
       "note": "蓝区整理，未分类，供应商/客户/成熟度待绿区复核"
     },
     "items": [
       { "编号": "CT-20260923-001", "目标主题": "", "技术点/子主题": "", "资讯标题": "",
         "摘要要点": "", "涉及厂商": "", "客户": "", "车型": "",
         "成熟度": "未说明", "原文日期": "", "来源": "", "栏目": "",
         "链接": "", "命中检索词": "", "备注": "" }
     ]
   }
   ```

## 四、输出与交接

- 产物放文件同步文件夹（如 `…\底盘新技术检索_@_\日期\tech_points.json`），绿区跑 `blue_to_ingest.py` 自动转候选、人工核对入库。
- 蓝区不直接写知识库（网络隔离，单向）。
