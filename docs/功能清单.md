# AI4KnowledgeNet 知识图谱工作台 · 功能清单与使用手册

> 版本：v0.5.0 ｜ 整理日期：2026-08-24
> 底层：FastAPI + NebulaGraph 3.8.3 + vis-network + 3d-force-graph（WebGL）
> 访问：浏览器打开 `http://<服务器IP>:8000`（浏览免登录；写入需登录）

---

## 一、总览

这个工作台把「散落在文件夹里的底盘/汽车技术资料」组织成一棵 **领域 → 板块(subdomain) → 主题/技术点(technology) → 文档(material)** 的知识网络，并提供**可视化、检索、编辑、AI 辅助入库、多人协作**五大能力。所有操作实时写入共享的 NebulaGraph。

> 📌 名词说明：本工具原称「材料(material)」，现统一显示为「文档」；内部数据结构不变。

---

## 二、功能清单（按模块）

### A. 可视化与视图

| 功能 | 说明 |
|------|------|
| **2D / 3D 双视图** | 顶部「二维 / 三维」一键切换；3D 用 WebGL 力导向图，2D 用 vis-network |
| **同心圆布局** | 领域/板块按扇形分区，层次清晰（默认） |
| **力导向布局** | 关联越多的节点越被斥力推开，适合看清网络结构 |
| **重新撑开** | 力导向下把重叠节点重新推开 |
| **缩放 / 拖拽 / 旋转** | 3D 可旋转视角；2D 拖拽画布；「适应」按钮一键居中 |
| **3D 节点标注** | 可开关；按层级（领域/子域/技术点/文档）选择显示哪些标签 |
| **图例** | 右下角显示各节点类型对应的颜色/大小 |
| **节点大小分级** | 领域最大、文档最小，一眼识别层级 |

### B. 检索与定位

| 功能 | 说明 |
|------|------|
| **关键字搜索** | 按技术点/领域/文档名搜索，支持中英文、模糊 |
| **类型筛选** | 搜索时可限定只查技术点/领域/子域/文档 |
| **高亮命中** | 在图上高亮显示搜索命中的节点（2D/3D 通用），未命中变暗 |
| **层级筛选（显示层级）** | 只看某一层：领域 / 子域 / 技术点 / 文档 |
| **层级范围** | 「含上层」或「仅本层」 |
| **领域筛选** | 只看某个领域（子库），多人协作时隔离不同知识域 |
| **节点列表** | 左侧列出当前节点，点击列表中某项即可聚焦 |

### C. 聚焦与探索

| 功能 | 说明 |
|------|------|
| **聚焦子图** | 点任意节点 → 显示它一跳/两跳内的邻居（所属层级 + 支撑文档），自动保留文档球体 |
| **只看选中** | 只显示当前选中点及其一跳邻居 |
| **节点详情抽屉** | 右侧弹出：节点标签、属性、邻居分组、来源链接 |
| **打开链接** | 材料节点可跳转到原文 URL / 复制共享盘路径 |
| **查最短路径** | 选起点+终点，`FIND SHORTEST PATH` 找两点间最短关联网，用于跨技术关联发现 |

### D. 图谱编辑（CRUD）

| 功能 | 说明 |
|------|------|
| **添加技术点** | 填名称、上一层技术簇（可多级）、描述、关键词；支持「提炼/译中」AI 辅助 |
| **添加支撑文档** | 填文档名、支撑的技术点、类型（文档/论文/专利/标准/资讯）、标题、摘要、来源链接 |
| **编辑节点/边** | PATCH 改属性；删除节点（连边级联）、删除单条边 |
| **撤回 / 重做** | 顶栏「↩ 撤回 / ↪ 重做」撤销或重做最近一次操作（按浏览器客户端隔离，只影响自己；需登录）|
| **操作审计** | 每次写入记录到 SQLite（`data/history.db`），可查历史；按客户端区分归属 |
| **数据即时落库** | 任何增删改实时写入 Nebula，刷新即最新态；幂等（IF NOT EXISTS）防重复 |

### E. AI 协助入库

| 功能 | 说明 |
|------|------|
| **LLM 状态检测** | AI 面板显示是否已配置可用的大模型服务（后端共享配置，团队免各自配 key）|
| **网页抓取 + 提炼** | 「网页抓取」：粘贴公开网页 URL → 后端抓取正文（自动读系统代理）→ 填入文本框 → 可继续抽取 |
| **自动抽取** | 粘贴文本/网页正文 → LLM 抽取「技术点 + 支撑文档」结构（可选译中文）|
| **可编辑抽取结果** | 抽取结果直接渲染成可视化表单：领域/子领域/技术点/文档/支撑勾选/备注全部可编辑，可增删 |
| **同名并入** | 已有同名技术点/文档标注「已存在·复用」，并入已有节点；没有则自动新建 |
| **生成协作提示词** | 把资料整理成提示词，交给 Cursor/助手人工处理 |
| **解析粘贴结果** | 把 Cursor 返回的 JSON 粘贴 → 解析 → 预览 |
| **确认写入** | 人工确认后的抽取结果一键写入图谱（需登录）|
| **提炼/译中** | 对描述做 AI 提炼或中译 |
| **规则/AI 复核** | import_review 支持 rule_check + AI 二次复核（QA 环节，先不写库）|

### F. 系统与运维

| 功能 | 说明 |
|------|------|
| **全貌（Overview）** | 一屏总览整图，按层预算控制画布规模、保证清晰 |
| **刷新** | 重新拉取数据 |
| **API 访问** | 页面顶部「API」链接，Swagger 文档（`/docs`） |
| **统计条** | 顶部显示各层节点数量（领域/子域/技术点/文档） |
| **MCP 服务** | 供 AI Agent（如 Cursor）经 `kg_*` 工具读写图谱，人机协同同一份数据 |
| **登录鉴权（只读/可写）** | 浏览免登录；写入（增删改、AI 入库）需登录写入口令；口令在 `.env` 的 `WRITE_PASSWORD` |
| **开机自启** | `scripts/start_service.bat` + 启动文件夹快捷方式，登录 Windows 自动拉起 Nebula + 后端 |

## 三、数据模型速查

**节点 Tag**：`domain`（领域）、`subdomain`（板块）、`technology`（主题/技术点）、`material`（文档）

**边**：
- `belongs_to`（子→父，层级归属）
- `supports`（文档→技术点，文档支撑）
- `relates_to`（技术点↔技术点，横向/交叉关联）

---

## 四、能力边界（当前已知）

- **登录鉴权（已加）**：浏览免登录，写入口令区分读写；按浏览器客户端隔离撤回/重做与操作归属。
- **无冲突提示（待补）**：多人同时改不同数据 OK；同一数据仍"后写覆盖先写"，暂无冲突提醒。
- **实时同步**：非自动推送，需刷新页面看他人改动。
- **文档存储**：元数据在 Nebula；文件本体走共享盘/链接，暂未接入对象存储。
- **批量导入**：主要靠脚本（ingest_*.py）+ AI 抽取，页面以增量录入为主。

## 五、一句话总结

> 一个「可视化 + 检索 + 编辑 + AI 抽取 + 多人共享」的底盘技术知识图谱工作台，把资料变成可检索、可推理、可持续生长的知识资产。
