## A. 丰富版（详细复盘 · 面试/项目展示用）

### 项目名
**AI4KnowledgeNet —— 汽车工程知识图谱工作台（AI 协作入库 + 技术情报雷达）**

### 背景与目标
公司内底盘/汽车技术资料散落在 PDF / PPT / Word / 论文中，靠文件名猜内容、靠经验联想关联，无法沉淀、检索与共享。
目标：从 0 到 1，把"资料"变成"可检索、可推理、可持续生长的知识资产"，并让 AI 与人在同一份数据上协作。

### 技术栈
- **后端**：Python · FastAPI · uvicorn · httpx · lxml · nebula3-python
- **存储**：NebulaGraph 3.8（图数据库，nGQL）主引擎；SQLite 承载操作日志/审计/候选队列
- **前端**：vis-network（2D）+ 3d-force-graph（3D · WebGL）力导向可视化
- **环境**：Windows + WSL / Docker；受限虚拟化环境（OpenStack VM，无嵌套虚拟化）下的适配
- **部署/DevOps**：Docker Compose 多服务编排、WSL 原生二进制降级方案、开机自启/定时任务自动化
- **AI**：接入华为内网推理服务（DeepSeek 系），LLM 结构化抽取；MCP 供 AI Agent 读写图谱

### 数据模型与架构演进（体现选型判断力）
- 判断"技术是**多分支向下发散、可交叉汇合**的网络（DAG）"，表格/文档表达不了 → 选型**图数据库**；
  `domain → subdomain → technology → material` 四类节点，`belongs_to / supports / relates_to` 三类边。
- 存储演进：早期用 SQLite 记录操作/审计 → 升级为 NebulaGraph 承载全量知识网络；无嵌套虚拟化环境用 **WSL1 原生安装 Nebula**，同时保留 Docker Compose 双路线。
- 后端分层 `routers → store → nebula_client → driver`；**子树作用域查询实现"领域隔离"**，同名节点不跨域误合并；**批量取数消除 N+1**。
- 前端 2D/3D 双视图、同心圆/力导向布局、聚焦子图与最短路径（`FIND SHORTEST PATH`）、层级与领域筛选，版本号抗浏览器缓存。

### 核心能力亮点（量化）
- **图规模**：4 领域 / 25 子域 / 233 技术点 / 241 文档，约 **500+ 节点、600+ 边**，多人实时共享。
- **AI 协作管线**：网页抓取（读取系统代理、HTML 语义容器+文本密度兜底）→ LLM 结构化抽取（定义 JSON schema）→ 可编辑预览 → 同名并入 → 确认写入；
  对 LLM 瞬时故障（429/503/超时）做**指数退避自动重试**，把偶发不可用对用户的冲击降到最低。
- **技术情报雷达（独立模块，全站最新能力）**：arXiv / Semantic Scholar / Crossref / RSS / Sitemap / 列表页 / 手工 URL 多源自动抓取 → 可用性探测 → 去重增量 → AI/人工审核 → 入库；
  支持 CSV/JSON 导出；设计了**蓝区（外网）采集 → 文件同步夹 → 绿区（内网）入库**的内外网打通方案。
### 工程化与健壮性（含 Docker/容器能力）
- **Docker Compose 多服务编排**：用官方 `vesoft/nebula-*` 镜像编排 NebulaGraph 的 **metad / storaged / graphd / studio** 四个服务，包含端口映射、数据卷持久化、健康检查与网络隔离——标准的容器化多组件交付。
- **受限环境降级部署**：宿主机为 OpenStack VM（无嵌套虚拟化）时，改用 **WSL1 + 原生二进制** 落地 Nebula，Docker Compose 保留为通用 Linux/Docker 环境的备选方案，体现**跨环境部署的应变与取舍**。
- **运维自动化**：`start_service.bat` 开机自启、WSL 启动脚本、SQLite 线程池跨线程访问修复（`check_same_thread=False` + 锁）、图数据**变更指纹检测 + 每日自动快照备份**、写入口令权限 + 每客户端隔离的撤回/重做 + 操作审计。

### 行业纵深（新能源/底盘前沿）
系统性整理并建模了 **11 大板块**架构与大量高质量行业材料，形成对新时代技术趋势的深刻认知：
- **线控底盘**：Steer-by-Wire、Brake-by-Wire（EHB→EMB）、主动/全主动悬架、后轮转向；
- **电动化**：800V 高压 + SiC 功率器件、轮毂/轮边电机、轴向磁通电机、电机油冷热管理；
- **整车架构**：CTC/CTB 电池底盘一体化、一体压铸（Gigacasting）、软件定义底盘/底盘域控；
- 理解"硬件定义汽车 → 软件定义汽车"的演进，以及功能安全（ISO 26262）与整车网络架构（E/E 升级）的关系。

> 我独立完成了"技术知识资产化"从选型、架构到落地闭环，并把最新的大模型能力接入到真实生产管线中——这段经历训练了我的**系统设计、AI 工程化、数据管道**与**领域建模**四大能力，恰好是构建世界模型/大模型应用最需要的核心素质。
